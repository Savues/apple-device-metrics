## 1. 对循环节点电压表的独立证实

本设备的厂商铭牌给出的充电电压上限为 **4.45 V**。套用第三方的节点阶跃
（在 200/250/300 各 −0.02 V，在 ≥1000 再额外 −0.05 V）：

| 区间 | 上限 |
|------|-------|
| 1–199（铭牌） | **4450 mV** |
| 200–249 | 4430 mV |
| 250–299 | 4410 mV |
| 300–999 | 4390 mV |
| ≥1000（**预测**） | **4340 mV** |

预测的 ≥1000 数值**与实测 `VacVoltageLimit = 4340 mV` 完全相等**。而 4450 mV
也与本设备的生命周期 `MaximumPackVoltage = 4450 mV` 相等，后者是另一个独立字段。
因此，这套阶梯从已知铭牌出发在**两个方向**上都得到了验证，而不仅仅是反推。

在 `iphone-01` 上，以其 4.50 V 铭牌做同样的计算也成立：在第 200 次循环时
4.50 → 4.48 V，与恰在 `CycleCount = 200` 时实测的 4480 mV 吻合，
且生命周期峰值 4496 mV 刚好低于 4500 mV。

**两个铭牌、两个相互独立的 iOS 版本、两个电芯平台，同一张一致的阶跃表。**
这大大增强了 −0.02 V / −0.05 V 阶跃幅度的可信度。注意绝对电压是相对于平台而言的
（顶档为 4.50 V 对 4.45 V），因此该表必须按设备套用，而不是作为通用的绝对阶梯。
它仍然不是 Apple 官方文档：节点边界和阶跃幅度仍是第三方逆向工程的结果，
只是恰好与两台设备完全吻合。

## 2. 对 §6（两个不同的健康度数字）的有力支持

`reference-01` 让这一区别再明显不过。有了它的厂商铭牌（2815 mAh / 3.83 V / 4.45 V），
与 `iphone-01`（3692 mAh / 3.887 V / 4.50 V）的比较现在是同口径的：

| 量 | `reference-01` | `iphone-01` |
|----------|----------------|-------------|
| `NCC / rated capacity` | 1623/2815 = **57.66%** | 3659/3692 = **99.11%** |
| `MaximumCapacityPercent`（Apple） | **73** | **101** |
| 差值 | **+15.34 pp** | **+1.89 pp** |

差值不是固定偏移：随着电池老化，它增大了约 8×。这排除了"取整方式不同"的解释，
并证实 Apple 的健康度数字使用的是其自己校准的基准（很可能还有不同的老化模型），
而不是简单地除以铭牌额定容量。

这里 `NCC / AppleRawMaxCapacity` 为 1623/1650 = 98.36%，它*也不是*健康度数字：
Raw 是一个会漂移的电量计估计值（见主证据文档 §5-6），因此该比值作为健康度没有意义。

另一处：`MaximumFCC = 2311` 和 `MinimumFCC = 64` 是生命周期极值，而非当前容量；
用其中任何一个作为健康度分母都是错误的。由 `AppleRawMaxCapacity` 推导出的约
2223 mAh"设计容量"（1623/0.73）在已公开的铭牌字段中没有对应项。
